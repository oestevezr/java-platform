# Lee el código en tres pasos

Antes de buscar una salida, distingue las reglas del lenguaje del comportamiento en ejecución.

1. **Compilación:** ¿los tipos, nombres y accesos son válidos?
2. **Ejecución:** ¿hay una excepción o una condición que cambia el recorrido?
3. **Resultado:** sigue los valores paso a paso.

Este apunte de muestra presenta el formato interactivo. El temario NETEC se completará con las referencias aportadas.
